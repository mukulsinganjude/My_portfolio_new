LEARNING NOTES

THREE-TIER CONCEPT

Separate responsibilities. Connect securely.

A common web architecture separates incoming traffic, application processing, and persistent data so each tier can be managed with clear boundaries.

  • Web tier: Nginx receives and routes requests.
  • Application tier: Tomcat runs the application layer.
  • Data tier: a relational database stores application data.

AWS EC2VPCNginxTomcatRDB

PROJECT CASE STUDY · INFRASTRUCTURE LEARNING

Goal: explore how a web tier, application tier, and relational database tier can be separated.

Architecture flow

Users → Nginx web tier → Tomcat application tier → relational database.

Technologies shown

AWS EC2 compute, a VPC network boundary, Nginx, Tomcat, and a relational database tier.

Security considerations

Plan subnet boundaries, security-group rules, database access paths, and separation between public entry and private services.

Operations follow-up

Document the intended deployment steps, health/log checks, and recovery notes in a runbook.

Scope note: this is an infrastructure learning project and architecture exploration, not a claim of a production deployment.
